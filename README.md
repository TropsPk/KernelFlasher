## 🚀 Tropsi Flasher features

- 🔍 &nbsp;View device slot information
- ⚡ &nbsp;Flash compatible kernel and recovery ZIP packages, including AnyKernel3 (AK3)
- 💽 &nbsp;Flash supported partition images, such as `boot.img`, `recovery.img`, and `vbmeta.img`
- 💾 &nbsp;Back up and restore kernel-related partitions
- 🔀 &nbsp;Toggle the mount and map status of `vendor_dlkm`
- 📝 &nbsp;Save `dmesg` and `logcat` logs

> [!NOTE]
> Image and package compatibility depends on the device, partition layout, and file format.
